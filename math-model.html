MiniMax-H3 — Math Model

Prompt → Video, as formulas.  $d$ = hidden dim, $N$ = sequence length, bold = tensors.

$$\text{prompt } P \;\longrightarrow\; \text{tokens } \mathbf{t} \;\longrightarrow\; \text{condition } \mathbf{c} \;\longrightarrow\; \text{latent } \mathbf{z} \;\longrightarrow\; \text{video } \mathbf{V},\ \text{audio } \mathbf{A}$$

1Text → tokens → embedding

Tokenize the string, then look each token up in the embedding table $E$.

$$\mathbf{t} = \text{tok}(P) \in \mathbb{N}^{L}, \qquad \mathbf{x}^{(0)} = E[\mathbf{t}] \in \mathbb{R}^{L \times d}$$

2Encoder (Qwen3-VL-32B) → conditioning

Transformer stack; H3 taps the hidden state at layer 50.

$$\mathbf{x}^{(\ell)} = f_\ell\!\left(\mathbf{x}^{(\ell-1)}\right),\ \ \ell = 1 \dots 50 \qquad\Longrightarrow\qquad \mathbf{c} = \mathbf{x}^{(50)} \in \mathbb{R}^{L \times d}$$

Each layer = attention + feed-forward with residuals:

$$f_\ell(\mathbf{x}) = \mathbf{x} + \mathrm{FFN}\big(\mathbf{x} + \mathrm{Attn}(\mathbf{x})\big)$$

Attention (score matrix is $N\times N$ → the $\mathcal{O}(N^2)$ cost):

$$\mathrm{Attn}(\mathbf{x}) = \mathrm{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}, \qquad \mathbf{Q}=\mathbf{x}W_Q,\ \mathbf{K}=\mathbf{x}W_K,\ \mathbf{V}=\mathbf{x}W_V$$

Feed-forward (token-wise; the memory culprit, see §7):

$$\mathrm{FFN}(\mathbf{x}) = \sigma\!\left(\mathbf{x}W_1 + b_1\right)W_2 + b_2, \qquad W_1 \in \mathbb{R}^{d \times 4d}$$

3Noise initialization (latent space)

Start from pure Gaussian noise in the compressed latent (space 16×, time 4×).

$$\mathbf{z}_1 \sim \mathcal{N}(\mathbf{0}, \mathbf{I}), \qquad \mathbf{z}_1 \in \mathbb{R}^{F' \times H' \times W' \times C}, \qquad H'=\tfrac{H}{16},\ W'=\tfrac{W}{16},\ F'=\tfrac{F}{4}$$

4Flow matching — the generator is an ODE

H3 (FLOW_AV) learns a velocity field $v_\theta$. Generation integrates an ODE from noise ($t{=}1$) to data ($t{=}0$), steered by $\mathbf{c}$:

$$\frac{d\mathbf{z}_t}{dt} = v_\theta(\mathbf{z}_t,\ t,\ \mathbf{c}) \qquad \mathbf{z}_1 = \text{noise} \ \longrightarrow\ \mathbf{z}_0 = \text{clean latent}$$

Training target (why it's regression, not classification) along the straight path $\mathbf{z}_t = t\,\mathbf{z}_1 + (1-t)\,\mathbf{z}_0$:

$$\mathcal{L} = \mathbb{E}_{t,\mathbf{z}_0,\mathbf{z}_1}\Big\|\, v_\theta(\mathbf{z}_t, t, \mathbf{c}) - (\mathbf{z}_1 - \mathbf{z}_0)\,\Big\|^2$$

5Sampling = discretizing the ODE (Euler)

Split $t\in[0,1]$ into $S$ steps; each step is one full DiT forward pass.

$$\mathbf{z}_{t-\Delta t} = \mathbf{z}_t - \Delta t \cdot v_\theta(\mathbf{z}_t, t, \mathbf{c}), \qquad \Delta t = \tfrac{1}{S}$$

Base $S=20$ (error $\sim\mathcal{O}(\Delta t)$). Turbo-LoRA distills $v_\theta\to v_\theta'$ so $S=4$–$6$ suffices.

$$\text{NFE} = S \times (\text{solver order})$$

6Latent → pixels & sound (VAE decode)

Continuous output (regression), then rescaled to bytes. No softmax over colors.

$$\mathbf{V} = \left\lfloor \big(\tanh(\mathrm{Dec}_{\text{vid}}(\mathbf{z}_0)) + 1\big)\cdot 127.5 \right\rceil \in [0,255]$$
$$\mathbf{A} = \left\lfloor \mathrm{Dec}_{\text{aud}}(\mathbf{z}_0)\cdot 32767 \right\rceil \in [-32768,\,32767]$$

7Cost model (why 8 GB is the fight)

Time:

$$T_{\text{total}} = \underbrace{\text{NFE}\cdot T_{\text{fwd}}(\text{res}\times\text{frames})}_{\text{sampling}} \;+\; \underbrace{T_{\text{enc}} + T_{\text{dec}} + T_{\text{up}}}_{\text{fixed}}$$

Speedup is bounded (Amdahl); $p$ = sampling fraction, $s$ = Turbo factor:

$$\text{speedup} = \frac{1}{(1-p) + \dfrac{p}{s}}$$

Peak memory (measured):

$$M_{\text{peak}} = \underbrace{M_{\text{fixed}}}_{\approx\,6.5\text{ GB}} + M_{\text{frames}}(F)$$

~88% of the real-tensor part was one int8 GEMM temporary:

$$M_{\text{int8mm}} = \underbrace{M \times N}_{\text{output } [M,N]} \times \underbrace{4\text{ bytes}}_{\text{int32}} \;\approx\; 2.24\text{ GB (one shot)}$$

8The exact optimization (bit-identical)

Rows are independent (per-row scale $s_i$), so block over rows $R_i$ — never materialize the full $[M,N]$:

$$\mathbf{Y}[R_i,:] = \big(\mathbf{X}_8[R_i,:]\; W_8^\top\big) \cdot (s_{R_i}\, s_w), \qquad \bigcup_i R_i = \{1..M\}$$
$$\Rightarrow\quad M_{\text{peak}}:\ 5.9\text{ GB} \to 3.9\text{ GB}, \qquad \Delta Q = 0 \ (\text{proven } \texttt{torch.equal})$$
